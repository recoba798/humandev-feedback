# 成人発達段階 簡易チェック — ご意見・お問い合わせ窓口

非公式の簡易ツール「成人発達段階 簡易チェック」へのご意見・お問い合わせを受け付けるためのリポジトリです。

- 本ツールは、ロバート・キーガン氏の成人発達理論を参考に独自に作成した非公式のものです。キーガン氏をはじめ、成人発達理論の研究者・著者・翻訳者・関連団体とは一切関係がなく、監修や承認も受けていません。
- 権利者・関係者の方から削除や修正のご依頼をいただいた場合は、内容を確認するまで該当箇所の公開を停止したうえで対応します。

## ご連絡の方法

[Issues](../../issues/new/choose) から、該当するテンプレートを選んでください。

**Issue は誰でも閲覧できます。** 氏名・連絡先などの個人情報や、診断の回答内容・自由記述は書き込まないでください。非公開での連絡が必要な場合は、その旨だけを Issue に書いていただければ、連絡方法をご案内します。
